# Cosmos Interactive runtime

`flashdreams-cosmos-interactive` provides the `cosmos_interactive` Python package:
the Cosmos3 transformer, checkpoint loading, tokenization, video codecs and
LiDAR codec. Applications supply their rollout and UI bindings.

For installation and launch commands, see
[Cosmos3 Nano Sim Auto](../cosmos3_nano_sim_auto/README.md).
