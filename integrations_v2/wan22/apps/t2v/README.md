# Wan 2.2 TI2V application

Launch the single-block Wan 2.2 application with a prompt and first frame.
`--image-path` is required and must point to an existing image:

The example below uses the first frame generated by FastVideo Causal Wan 2.2
T2V for the prompt “A cat surfing”:

![FastVideo Causal Wan 2.2 cat-surfing first frame](assets/fastvideo-causal-wan22-cat-surfing-first-frame.png)

```bash
uv run --package flashdreams-wan22 flashdreams-run-v2 \
  t2v-wan22-ti2v-5b --output-path clip.mp4 -- \
  --prompt "A cat surfing" \
  --image-path integrations_v2/wan22/apps/t2v/assets/fastvideo-causal-wan22-cat-surfing-first-frame.png \
  --no-compile
```

See the [shared T2V guide](../../../../apps/t2v/README.md) for controls, common arguments, defaults, and tests.
