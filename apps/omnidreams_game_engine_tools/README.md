# Omnidreams Game Engine tools

Offline map exporters, installed separately from `omnidreams-game-engine`.

- `omnidreams_game_engine_tools.preview.write_game_map_preview` writes an SVG overview.
- `omnidreams_game_engine_tools.spawn_preview.write_spawn_first_frame_preview` writes a PNG for a selected spawn.

The [Crazy Robotaxi map CLI](../crazy_robotaxi_tools/README.md) exposes both.
The engine retains the loader, compiler, and fallback renderer used during gameplay.
