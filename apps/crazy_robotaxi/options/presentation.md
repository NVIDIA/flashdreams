# PRESENTATION

[Options index](../OPTIONS.md)

These fields apply when saved, without a process restart, unless a command-line override is active.

| On-screen label | Defined by | CLI flag | What it changes |
| --- | --- | --- | --- |
| **Width:** | Crazy Robotaxi | `--display-width` | Presentation width in pixels; None uses the model output width. Set together with the height. |
| **Height:** | Crazy Robotaxi | `--display-height` | Presentation height in pixels; None uses the model output height. Set together with the width. |
| **Hud Enabled:** | Crazy Robotaxi | — | Shows the gameplay HUD. |
| **Show Fps:** | Crazy Robotaxi | `--show-fps`, `--no-show-fps` | Shows the frame-rate counter. |
| **Show Current Prompt:** | Crazy Robotaxi | — | Shows the world-model prompt. |
| **Show Control Hints:** | Crazy Robotaxi | — | Shows the control help on the HUD. |
| **Show Live Edit Buttons:** | Crazy Robotaxi | — | Shows live-edit ability buttons. |
| **Live Edit Mapping Location:** | Crazy Robotaxi | — | Places live-edit mappings in `buttons` or `control hints`. |
