Infra#

The flashdreams.infra package defines the swappable abstractions that every recipe plugs into: a config system, an encoder / diffusion-model / decoder triple, and the streaming inference pipeline that drives them.

Config#

Every component is built from a frozen InstantiateConfig dataclass via config.setup(). This makes the full configuration tree printable, hashable, and trivially serialisable.

Pipeline#

The pipeline is the top-level streaming inference loop. It autoregressively generates one chunk of latent video at a time by running the encoder, the diffusion model, and the decoder back-to-back, threading per-chunk caches through every component.

Advance the AR cache using the clean latent from generate().

Renoises the clean latent to DiffusionModelConfig.context_noise, then defers the actual cache-update forward(s) to Transformer.finalize_kv_cache() (one network for vanilla transformers, both for Wan 2.2’s dual-network DiT, etc.).

Run the full denoising loop and return the clean latent.

Schedulers are shape-agnostic: every internal op is elementwise broadcast against per-step scalar sigmas. In practice initial_noise is a video latent [B, C, T, H, W].

Parameters:

class FlowMatchScheduler(
config: FlowMatchSchedulerConfig,
)[source]#

Bases: Scheduler

Flow-matching scheduler (DiffSynth-style step).

Self-forcing renoise loop – at each iteration the network’s flow prediction is converted to an x0 estimate, then re-noised at the same sigma to feed the next iteration. The final x0 is returned.

x_t = initial_noise
for t in denoising_step_list:
    v = predict_flow(x_t, t)
    x0 = x_t - sigma(t) * v
    x_t = (1 - sigma(t)) * x0 + sigma(t) * eps    # re-noise at same t
return x0

Example:

scheduler = FlowMatchSchedulerConfig(
    num_inference_steps=4,
    shift=8.0,
    denoising_timesteps=[1000, 750, 500, 250],
).setup().to("cuda")
clean = scheduler.sample(initial_noise=noise, predict_flow=fn)

Note

Schedule buffers are pinned to fp32 even after module.to(bf16) (see _apply()); integer timesteps like 1000 would otherwise round to 1024.

Encoder#

Encoders turn raw conditioning (text prompts, reference images, …) into the latent tensors consumed by the transformer. Like every other component, they are stateful across AR steps via an EncoderAutoregressiveCache.

Decoder#

Decoders turn the latents emitted by the diffusion model back into pixel frames. They keep a DecoderAutoregressiveCache so the streaming pipeline can decode one chunk at a time with the correct temporal context.
