Cosmos3 Nano Sim Bimanual

Checkpoint and model card Cosmos 3 project Blog

Cosmos3 Nano Sim Bimanual generates robot-manipulation video from an opening image, a prompt, and controller actions. Try it with HandDreams.

Quick Start

HandDreams

Use Linux x86_64/aarch64 with glibc 2.35+, OpenSSL, Python 3.12 venv support, and an NVIDIA GPU with CUDA, Vulkan, and NVENC. RTX PRO 6000 has been tested. A GB300-only host cannot run this CloudXR setup. Allow about 61 GB for model shards and the merged cache, plus dependencies, decoder weights, and scenes. Use Chrome or Chromium with graphics acceleration. No headset or physical controllers are required for the steps below.

Install uv and clone FlashDreams, then run from its root. The checkout must contain integrations_v2/cosmos3_nano_sim_bimanual. Your Hugging Face account needs access to the checkpoint above and agibot-world/AgiBotWorld-Beta.

Setup isaac-teleop if not done already.

export HF_TOKEN="<your-hugging-face-token>"
# Note: `--accept-eula` implies that you have already accepted the 'Isaac Teleop/CloudXR eula' terms. If not, follow the setup instructions for isaac-teleop setup.
uv run --no-project --python 3.12 python \
  integrations_v2/cosmos3_nano_sim_bimanual/apps/handdreams/launch.py server \
  --address 127.0.0.1 --accept-eula

For a remote browser, replace 127.0.0.1 with the server's reachable LAN IPv4. First startup installs dependencies, downloads the model and scenes, and warms up the model. Keep the terminal running.

Connect virtual controllers or physical controllers, select a scene, and start controlling the hands.

Demo Presets Controls Demo Arguments

Demo Presets

HandDreams

Preset Description
handdreams GA checkpoint, four denoising steps, TAEHV2 Super decoder, 640 × 352 output.

The launcher selects this preset and prepares dependencies. Default scenes are Fold the T-shirt, Fold the shorts, and Open the tissue box. No checkpoint override or S3 credentials are needed.
