Documentation contributions
---------------------------

The site is two Sphinx projects served from a single GitHub Pages
deployment:

- ``docs/landing/source/`` — the landing, benchmarks, and community
  pages on the ``nvidia-sphinx-theme``. The page you are reading lives
  here.
- ``docs/source/`` — the API reference, model pages, developer guides,
  and CLI reference on the ``furo`` theme. Served under ``/docs/``.

A few notes specific to doc PRs:

- ``warningiserror = True`` on both projects — a broken ``:doc:`` or
  ``:ref:`` link fails CI. Use
  ``uv run sphinx-build -W -b html docs/landing/source build/landing``
  and
  ``uv run sphinx-build -W -b html docs/source build/docs`` to reproduce
  locally.
- The landing project uses a small set of shared ``fd-*`` components
  defined in ``docs/landing/source/_static/custom.css`` plus
  ``sphinx_design`` directives. Prefer composing existing components
  over inline CSS or ad-hoc classes.
- API reference pages are generated by autodoc from docstrings. Doc
  fixes that touch ``docs/source/apis/*.rst`` should generally be paired
  with a docstring fix in the source module.

.. admonition:: New components or assets?
   :class: fd-callout

   If you find yourself reaching for inline ``style=""`` attributes or
   new ``_static/`` files, please open an issue first and tag it
   ``site`` — the site's component vocabulary is intentionally narrow
   so the look stays consistent.
