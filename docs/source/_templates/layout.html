{% extends "!layout.html" %} {# Body-class hooks for the FlashDreams marketing surfaces. Two related but distinct classes are emitted onto : * ``fd-layout-landing`` — the strictest hook. Drops the *secondary* TOC sidebar and widens the article column. Used on pages whose content IS the navigation (the master doc; opt-in via ``:layout: landing`` on any other page). * ``fd-layout-marketing`` — the looser hook. Hides docs-y header chrome (logo version subtitle, search button) so a product-y page does not read as "docs that happen to have a hero". Applied to the same set of pages whose primary sidebar is already hidden in ``conf.py``'s ``html_sidebars`` (the master doc, ``benchmarks/**``, ``community/**``). Authors can also opt in via ``:layout: marketing`` on any other page. Sphinx surfaces docinfo fields via the ``meta`` template variable, so ``:layout: landing`` / ``:layout: marketing`` at the top of an RST file gets reflected here. Note: ``fd-layout-landing`` implies ``fd-layout-marketing`` — a landing page never wants the docs chrome either — so we append both whenever the landing class is added. #} {%- block body_tag %} {%- set fd_body_classes = [] %} {%- set fd_layout = (meta.get('layout') if meta is defined and meta is not none else none) %} {# Landing-class trigger: master doc or explicit opt-in. #} {%- if fd_layout == 'landing' or pagename == master_doc %} {%- set _ = fd_body_classes.append('fd-layout-landing') %} {%- set _ = fd_body_classes.append('fd-layout-marketing') %} {%- elif fd_layout == 'marketing' or pagename.startswith('benchmarks/') or pagename.startswith('community/') %} {%- set _ = fd_body_classes.append('fd-layout-marketing') %} {%- endif %} {%- endblock %}
