Documentation contributions
---------------------------

The site is a single Sphinx project at ``docs/source/`` on
``pydata-sphinx-theme``. A few notes specific to doc PRs:

- ``warningiserror = True`` — a broken ``:doc:`` or ``:ref:`` link
  fails CI. Reproduce locally with
  ``uv run --no-project sphinx-build -W -b html docs/source _build``.
- The site uses a small set of shared ``fd-*`` components defined in
  ``docs/source/_static/custom.css`` plus ``sphinx_design`` directives.
  Prefer composing existing components over inline CSS or ad-hoc
  classes.
- API reference pages are generated by autodoc from docstrings. Doc
  fixes that touch ``docs/source/apis/*.rst`` should generally be paired
  with a docstring fix in the source module.

.. admonition:: New components or assets?
   :class: fd-callout

   If you find yourself reaching for inline ``style=""`` attributes or
   new ``_static/`` files, please open an issue first and tag it
   ``site`` — the site's component vocabulary is intentionally narrow
   so the look stays consistent.
