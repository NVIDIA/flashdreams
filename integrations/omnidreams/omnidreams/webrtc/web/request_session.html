Telemetry — all values are per chunk (8 RGB frames = 2 latent frames). FPS = 8000 / latency(ms).

Server Latency = gen_ms + enqueue_ms
start: just before the model generates the chunk
end: just after the chunk is handed to the transport
= model generation (+ VAE decode & H.264 encode in pixel mode) + emit/deliver (token: wait-for-client-ack + SAS encode + send)

Client Latency = WebGPU VAE decode (token modes)
start: just before the decode() call
end: when decode() resolves
= queue wait + WebGPU VAE decode + display transform

Payload = wire bytes for the chunk × 8 (bits)
token/SAS: exact bytes sent; pixel: WebRTC byte counter, scaled to one chunk

Counted by neither: network transit, chunk assembly, canvas present.
